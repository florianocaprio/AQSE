# AQSE replicated paper-study extension

## Status and scientific boundary

This document describes implemented experimental infrastructure. It does not
record a completed 30-replica result. No historical AQSE TEST artifact is read,
reopened, regenerated, or reinterpreted by this extension.

The protected circuit and QNG implementation remain in
`backend/app/quantum/user_pipeline/tqk8.py` and `sampler_qng.py`. The extension
calls the NumPy exact-state simulator only and does not submit hardware jobs.

Null, negative, and inconclusive outcomes are retained. Passing a positive
mechanism control is a software sanity check, not evidence about real sensors
or quantum advantage.

## Replicated protocol

`run_replicated_study` defaults to 30 independent replicas. Each replica:

1. derives disjoint dataset, split, QNG, classical, and control seeds from the
   declared base seed;
2. generates a new AQSE white-noise-regime corpus through the existing sensor
   simulator and feature extractor;
3. creates a stratified 60/20/20 TRAIN/VALIDATION/TEST split;
4. fits the phase-direct TRAIN-only encoder;
5. runs up to ten protected one-step QNG updates on a balanced TRAIN bank;
6. selects theta/checkpoint and precomputed-kernel SVC C on VALIDATION only;
7. fits all classical comparators on the same TRAIN split and performs any
   declared selection on the same VALIDATION split;
8. freezes selections before opening the replica's TEST observations;
9. predicts without labels, opens TEST labels once, publishes one evaluation,
   and closes its append-only ledger.

Every theta checkpoint's TRAIN kernel receives spectral diagnostics: complete
eigenvalue spectrum, maximum-eigenvalue/trace ratio, and effective rank
`exp(H(p))` for normalized non-negative eigenvalues.

The default simulator workload is intentionally substantial. Unit tests use
small isolated fixture datasets and do not constitute scientific replicas.

## Pre-registered replica counts

The following decisions were frozen on 2026-09-16, before launching the
30-replica primary scientific study:

- An initial four-replica negative-control pilot was used only to assess the
  stability of the software check. Its RBF interval marginally excluded chance,
  demonstrating that four replicas were insufficiently stable for this control.
  The pilot is non-confirmatory, is excluded from every aggregate result, and
  cannot be pooled with the frozen control run.
- The negative permutation control is fixed at **12 independent replicas**. The
  count was chosen after the four-replica stability pilot and before the primary
  study. It must not be reduced, extended, or rerun with replacement seeds in
  response to its observed accuracy or confidence intervals.
- The positive mechanism-aligned control is fixed at **12 independent
  replicas**, with base seed `3_003_001`. Each replica uses 200 independently
  generated TQK-teacher examples before its frozen stratified split. This count
  and seed were fixed before executing the scientific control and must not be
  changed after inspecting any control result.
- The primary replicated study is pre-registered at **30 independent replicas**.
  No interim result may change this count, its seed schedule, the declared
  methods, or the analysis. There is no performance-based early stopping. All
  30 replicas must complete under the frozen protocol, or the study must be
  reported as incomplete or failed.
- Any future change to either replica count constitutes a new protocol version
  with a new seed namespace and separately reported evidence. Results from that
  new protocol must not be silently pooled with this study.

The four-replica pilot and the 12-replica automated fixture run performed during
software validation are not the primary scientific study and do not authorize
access to any historical TEST. This pre-registration is committed with the
implementation so that the rule predates any primary-study TEST result.

## Classical comparators

- RBF-SVC, with the existing C/gamma grid selected on VALIDATION;
- one-hidden-unit tanh MLP: 11 trainable weights/biases, the closest
  under-capacity integer-width 8D binary MLP to the VQC's 16 theta parameters;
- 256-component random Fourier feature map plus a linear SVC, using the
  eight-qubit Hilbert-space dimension only as a capacity reference;
- gradient boosting with 100 estimators, learning rate 0.1, and depth 3.

Matching parameter or feature-space counts does not establish equivalence of
hypothesis classes or compute budgets.

## Controls

`permutation_control` changes TRAIN labels only, using a seed namespace
independent of each replica seed. VALIDATION and TEST labels remain untouched,
and every control TEST is sealed and single-use. A valid negative control is
reported as a 95% interval containing balanced accuracy 0.5; it is not evidence
that the unpermuted model is scientifically correct.

`positive_control_dataset` uses labels generated by a contrast between two
fixed TQK teacher states. It is deliberately aligned to the tested mechanism so
that the code path has a falsifiable sanity check. It is not a synthetic proxy
for field sensor performance and cannot support an advantage claim.

## Aggregation and reporting

Across replicas, the implementation reports:

- mean quantum-minus-classical balanced-accuracy delta for each baseline;
- a 95% percentile-bootstrap interval over independent replicas;
- two-sided paired Wilcoxon signed-rank results using Pratt zero handling;
- interval estimates for quantum and classical balanced accuracy;
- interval estimates for selected-kernel diagnostics;
- positive- and negative-control summaries when supplied.

The pre-registered primary quantum-advantage comparison is quantum TQK versus
RBF-SVC on TEST balanced accuracy across the 30 paired replicas. Evidence
supports the criterion only if both conditions hold: the 95% bootstrap interval
for the mean paired delta has a lower bound strictly greater than zero, and the
two-sided paired Wilcoxon p-value is below 0.05. Macro-F1 and comparisons with
MLP, RFF, and gradient boosting are secondary evidence and cannot rescue a
failed primary criterion.

The aggregate JSON uses native unrounded floating-point serialization. Every
aggregate performance and diagnostic estimate is represented by a point,
lower bound, and upper bound. Wilcoxon p-values are inferential test outputs,
not effect-size intervals or probabilities that a hypothesis is true.

## API sketch

```python
from pathlib import Path

from app.paper_study import run_replicated_study, write_aggregate_report

study = run_replicated_study(
    n_replicas=30,
    base_seed=3_001_001,
    output_dir=Path("/artifacts/paper-replicated-study-v1/primary"),
)
write_aggregate_report(
    Path("/artifacts/paper-replicated-study-v1/report.json"),
    study,
)
```

An existing output directory is rejected. A partially opened or completed TEST
ledger cannot be reused as permission to rerun a replica.

## Report-recovery incident and procedure

The preregistered execution at experiment commit
`091acf2e98b2b88720730eea276e253f0c96f5a6` completed 30 main replicas,
12 negative-control replicas, and 12 positive-control replicas. Each of the 54
replicas published its result and closed its four-event TEST ledger. The process
then failed while writing the root aggregate report because
`selected_kernel_diagnostics` still contained nested Pydantic
`IntervalEstimate` objects at the `json.dumps` boundary.

This was a reporting defect, not a scientific-execution failure. The correction
converts those interval models with `model_dump(mode="json")`; it does not alter
`IntervalEstimate`, statistical formulae, seeds, precision, or the protected
TQK8/QNG implementation. The original execution directory remains immutable.

The dedicated recovery command validates all stored `aggregate.json` and
`result.json` files, exact replica indices, source identity, byte hashes, ledger
chains, and environment versions. It hashes TEST `.npy` files as opaque bytes;
it never deserializes observations or labels and cannot invoke dataset
generation, fitting, prediction, TEST loaders, or evaluation publication. It
publishes through a staging directory into a separate sibling output and is
idempotent after the completion marker is present.

The reproducible command is:

```bash
python -m scripts.finalize_paper_replicated_study \
  --source /source/execution-091acf2e98b2-3001001 \
  --output /output/execution-091acf2e98b2-3001001-report-recovery-v1 \
  --reporting-source-commit <full-corrective-commit-sha>
```

The container invocation must mount `/source` read-only and a distinct
`/output` path read-write. The report records the experiment commit separately
from the later reporting commit. Saved per-replica runtime sums are reported as
such; the unavailable original wall-clock duration is not reconstructed.

Completing the package is not scientific approval. The final conclusion remains
limited to the preregistered paired TEST balanced-accuracy criterion in this
synthetic exact-state simulator domain; it is not a QPU-compute or field-sensor
advantage claim.
